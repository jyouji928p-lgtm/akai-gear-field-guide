# AKAI Gear Field Guide

AKAI機材の設定ガイド、初心者向けクイックマニュアル、DAW選び、トラブル解決、機材比較をまとめた日本語の静的サイトです。

## 使い方

- `index.html` をブラウザーで開くとローカルで閲覧できます。
- GitHub Pagesを有効にすると、ブラウザーからアクセスできるサイトとして公開できます。
- 機材の選択やマイリストなど、一部の情報は利用中のブラウザー内に保存されます。共有チャットのサーバー機能は含まれていません。

## 内容

- AKAI機材を選んで切り替える機種別ガイド
- 機能検索、設定手順、DAWアプリの説明
- トラブルシューティングとサポートAI
- AKAI製品の比較と目的別の候補探し
- BPM計算、個人用チェックリスト、演奏メモ

サイトは単一のHTMLファイルで動作し、外部ライブラリを必要としません。製品仕様や対応状況は変わることがあるため、各機種の公式情報も併記しています。
