購入後、最初にしておくことは？

inMusic Software CenterのMy HardwareからMPK mini IVを選び、利用可能なファームウェア更新を確認します。更新中は他のMIDIアプリを終了してください。

Akai公式トラブルシューティング ↗
マニュアルにあるMIDIポート名が見つからない

まずファームウェアが最新か確認してください。Windowsでは古い専用Akai MIDI Driverが原因になることもあります。現在の案内ではMPK mini IVはクラスコンプライアントで、専用ドライバーは通常不要です。

Akai公式ドライバー案内 ↗
DAW／PluginモードでProgram EditやSaveが使えない

DAW／Pluginプリセットはスクリプト互換性を保つため編集・上書きできません。SHIFT＋PLUGIN/DAWでUser Presetを読み込み、SHIFT＋OCT−で編集します。

Akai公式トラブルシューティング ↗
「Program Protect!」と表示される

Factory Presetを編集中の表示です。User Presetへ切り替えてから編集してください。User PresetはSHIFT＋PLUGIN/DAWで選びます。

Akai公式の案内 ↗
DAW接続中にアルペジオやNote Repeatが鳴らない

ARPのClockがExtの場合、DAWから外部クロックを受信する必要があります。DAWを再生し、必要に応じてDAW側のMIDI Clock送信を有効にしてください。単独で使う場合はClockをIntへ戻します。

Akai公式トラブルシューティング ↗
DAW／PluginモードでパッドのCCやProgram Changeが使えない

スクリプト対応モードでは、SHIFT＋パッドがDAW操作などに割り当てられています。CC／Program Changeを使う場合はUser Presetに切り替えて設定します。

Akai公式トラブルシューティング ↗
WindowsでStudio Instrument Collectionの画面や操作子が連携しない

Pluginモードになっているか確認し、Studio Instrument Collectionの画面をクリックしてアプリにフォーカスを戻します。別アプリへ切り替えると制御スクリプトの接続が外れる場合があります。

Akai公式トラブルシューティング ↗
SICのVSTで鍵盤とパッドを同時に鳴らせない

SICのVST版は、一度に鍵盤系またはドラム系のどちらか一方を扱います。両方を使うにはStandalone版、またはDAW内でSICの複数インスタンスを使います。

Akai公式トラブルシューティング ↗
設定メニューから抜けられない

PLUGIN/DAWボタンはメニュー中はホームボタンとして働きます。押すとホーム画面に戻り、その後は通常のPlugin／DAW切替ボタンとして使えます。

Akai公式トラブルシューティング ↗
サステインペダルの動作が逆になる

Global Menu → Sustを開き、NormからInvへ切り替えます。MPK mini IVはNormally Openペダルを標準としているため、Normally ClosedペダルではInvが必要です。

Akai公式トラブルシューティング ↗
DAWのテンポにアルペジオが同期しない

ARP設定のClockは初期状態でInternalです。DAW同期にはExtへ変更し、DAW側からMIDI Clockを送信します。

Akai公式トラブルシューティング ↗
ファームウェア更新後、macOSで表示や操作がつながらない

DAWやMIDIアプリを終了し、Audio MIDI Setup → MIDI StudioからMPK mini IVデバイスを削除してからUSBをつなぎ直し、アプリを再起動します。

        まずは付属ソフトから

        Ableton Live Lite 12

        MPK mini IVに付属

        まず一つ選ぶならこれ。鍵盤やパッドの演奏を録音し、ループを重ねて曲にできます。

        Windows / macOS · MPK mini IV専用マップ対応
        くわしい説明›

        Session Viewでは短いループやフレーズを組み合わせ、Arrangement Viewで曲の流れに整理できます。MPK mini IVの鍵盤でMIDIを録音し、付属の音色やエフェクトを使って制作できます。

        向いている人：付属DAWから始めたい人、ループを重ねながら曲のアイデアを作りたい人。

        Ableton公式 ↗

        MPC Beats

        無料

        ドラムパッドでビートを作るのが中心ならおすすめ。AkaiのMPCに近い制作スタイルです。

        Windows / macOS · ビート制作向け
        くわしい説明›

        向いている人：MPKのパッドを使ったビート制作や、サンプルを並べる作り方を試したい人。

        GarageBand

        Mac向け・無料

        Macで手軽に録音や作曲を始めたい人向け。MPK mini IV用のコントロールマップもあります。

        macOSのみ · 対応マップはGarageBand 10.4.12以降

        内蔵音源やApple Loops、Drummerを使って曲を作り、MPK mini IVから鍵盤演奏を録音できます。ボーカルや楽器の録音、編集、ミックスにも対応します。

        向いている人：Macで、ドラム・鍵盤・録音を一つのアプリで手軽に試したい人。
